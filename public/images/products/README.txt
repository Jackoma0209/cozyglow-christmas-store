CozyGlow™ Product Media Slots
=============================

Real optimized product photography is installed in this directory (`public/images/products/`), plus `public/images/og-cozyglow.jpg` for social sharing.
The HeroProductBuyBox, CheckoutDrawer, SuccessPage, and ReviewsGrid components display these images automatically and fall back cleanly to the CSS CottageVisual scenes if any file is removed.

Installed files:
- 01-chimney-mist-hero.jpg
- 02-warm-window-glow.jpg
- 03-essential-oil-fill.jpg
- 04-mantel-village-setup.jpg
- 05-gift-box-unboxing.jpg
- review-scale-hands.jpg
- review-kitchen-counter.jpg

You can replace any file in place or add `chimney-mist-loop.mp4` (and wire `videoSrc` on slide 1 in `src/config/product.ts`) anytime.
