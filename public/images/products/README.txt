CozyGlow™ Product Media Slots
=============================

Drop real product photography and video files into this directory (`public/images/products/`).
The HeroProductBuyBox gallery will automatically display them and fall back seamlessly to the CSS CottageVisual scenes whenever any file is missing.

Expected filenames:
- 01-chimney-mist-hero.jpg (or .webp / .png)
- 02-warm-window-glow.jpg
- 03-essential-oil-fill.jpg
- 04-mantel-village-setup.jpg
- 05-gift-box-unboxing.jpg
- chimney-mist-loop.mp4 (optional 3-second looping hero video)
